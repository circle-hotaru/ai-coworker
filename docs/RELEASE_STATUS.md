# 验证与发布范围

本仓库包含经过匿名化和配置化的项目扩展源码及测试，固定上游版本以 upstreams.json 为准。
所有 examples 角色、MAC 和公司内容为虚构示例。

本次源码准备验证：

- 桥扩展 51 项 Python 测试通过，包含 8 项配置登记测试。
- ASR 管理工具 4 项测试通过（mock，未发送录音）。
- 固定上游加固件覆盖层的 110 项主机测试通过。
- 播报插件 27 项断言、协作守卫 15 项断言、动作插件 3 项测试通过。
- 公开内容扫描与文件清单完整性检查通过。

测试使用现有开发机依赖，不等于在全新机器完成安装验证。

本导出版不继承原部署日志、历史固件索引或旧硬件验收结论。完整 ESP-IDF 编译、
全新环境依赖安装、Gateway 插件运行时兼容及实体硬件验收仍须在发布二进制前完成。
tests 验证的是协议、隔离与去重等代码路径，不构成跨设备可靠性保证。

发布前运行 python3 scripts/check_public.py，并审查 Git 暂存区与拟发布历史。
自动扫描仅作辅助；凭据扫描无命中不等于所有可能敏感信息都已被证明不存在。
