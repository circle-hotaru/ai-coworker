# 架构与边界

硬件通过局域网 OTA 获得 WebSocket 地址；桥处理 VAD/ASR，把当前用户输入交给
本机 OpenClaw，再通过 EdgeTTS 将回复播回硬件。OpenClaw 提供实际任务工具。

连续模式在回复播完后继续监听，空白监听约 5 秒结束；“新任务”前缀创建独立任务。
麦克风没有物理断电；处理中由软件抑制后续输入。唤醒词取决于使用者的固件资源，
示例默认按键启动，不宣称自定义词可用。

后续播报：插件只提取允许 Agent 的硬件来源会话，loopback 入队；桥仅接受已登记任务。
通知按设备隔离、去重；设备仅 Idle 接收，同源音频校验与终态 NVS 去重保留。
桥离线时 OpenClaw 插件没有持久 outbox，事件可能丢失。设备重启后须重新 OTA 登记地址。

长任务等待使用心跳和字幕，软超时不会重复提交。连接中断不等于后台任务已取消，
目前没有跨重连结果恢复保证。MAC 分流和 LAN 来源检查不等于强设备认证。

StackChan：固定短舞蹈、限幅、真实舵机限位/反馈检查、停止后回正和释放扭矩。
工具仅指定 Agent 可见，桥动作入口仅 loopback；保留硬件来源校验，不提供任意角度接口。
适配范围不包括 LED、NFC、头顶触摸或遥控。回答触发动作和手动停止逻辑保留。

默认本地 FunASR，需自行下载模型。可选讯飞 ASR 和 EdgeTTS 需要网络服务，
录音/文本会发送到所选服务；本项目不是默认完全离线系统。
