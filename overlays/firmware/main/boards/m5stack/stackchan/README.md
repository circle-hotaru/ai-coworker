# StackChan / CoreS3

ESP32-S3、16 MB Flash、8 MB quad PSRAM、320×240 横屏。使用该目录的 config.json
与 ESP-IDF 6.1，经 scripts/build.py 选择精确板型；不要直接复用其他设备的构建目录。

界面支持字幕、状态、静音与麦克风点按；聆听时再次点按提交。头像区域长按启动固定动作，
动作时点按停止。动作受到角度、真实舵机限位、反馈、回正和释放扭矩约束。
NVS 缺少该设备的校准值时禁用动作。UART1 TX6/RX7，适配的串行舵机 ID 为 1/2。

独立动作端点使用 8020；空闲通知端点使用 8021，固件标签为 Operator。
来源限定为所配服务器，音频须同源；保留设备空闲状态限制和终态去重。
使用环境应为受信任局域网。这些来源检查不替代完整设备认证。

LED、NFC、头顶触摸和遥控未适配。本目录不包含个人头像或原设备校准数据。
发布镜像前须重新编译、核对具体设备分区与资源，并做实机验证。
