# Waveshare ESP32-S3-Touch-AMOLED-1.75

使用原板型配置分别选择非 C 与 C 变体。非 C 适配设备为 16 MB Flash，C 适配设备为
32 MB Flash，均使用 8 MB PSRAM；实际配置和分区必须与设备相符。

圆屏界面支持字幕、静音与麦克风点按；聆听时再次点麦克风会立即提交。
这两个变体关闭自动调暗/关机以支持空闲通知，功耗和电池续航需要使用者评估。

8021 通知端点只在 Idle 接受播放，来源与音频服务器受限，终态 ID 在 NVS 去重。
非 C 固件端点标签为 Reviewer，C 为 Researcher；桥配置中的 firmware_label 必须对应。
角色的 Agent ID 可独立配置，不需要与固件标签相同。

通过 scripts/build.py 串行构建精确变体；此目录不提供私人头像、预编译资源或烧录镜像。
新设备首次部署应按上游流程核对 Flash、分区、资源和恢复方法，不能跨板互刷。
